# Пропозиція дизайну розширення

**Статус: пропозиція, ще не реалізована.** Референс: темний popup із великими округлими картками, світлим текстом і яскравим лаймовим акцентом. Зберігаємо стиль, але не переносимо пошук, список акаунтів і рекомендації: розширення працює тільки з відкритим листом Gmail.

## Popup після натискання іконки

Ширина близько 380 px. У ньому налаштування й стан підключення, а висновки по конкретних повідомленнях залишаються біля цих повідомлень у Gmail.

```text
╭────────────────────────────────────╮
│ ◈ Fishing Analizer              ⚙  │
│ Перевірка відкритого листа Gmail   │
│                                    │
│ Модель                             │
│ [ Локальна Laya ] [ Jev / хмара ]   │
│                                    │
│ ╭────────────────────────────────╮ │
│ │ Backend: 127.0.0.1:8787        │ │
│ │ ● Підключено                   │ │
│ ╰────────────────────────────────╯ │
│                                    │
│ Результат з’явиться біля листа.     │
│ [ Відкрити налаштування ]          │
╰────────────────────────────────────╯
```

«Підключено» означає лише доступність backend, не готовність обох моделей. Якщо перевірки підключення немає, цей рядок не показуємо.

## Картка біля повідомлення Gmail

```text
╭────────────────────────────────────────────────╮
│ ⚠ Потрібна перевірка                     Laya  │
│                                                │
│ Спостережувані ознаки                          │
│ • Домен відправника й посилання різняться.     │
│ • Видима адреса не збігається з цільовою.      │
│                                                │
│ Оцінка моделі: потрібна перевірка               │
│ Це попередня оцінка, не гарантія безпеки.      │
╰────────────────────────────────────────────────╯
```

Домени й ознаки показуємо тільки з фактично зчитаних полів, як звичайний текст. Оцінку моделі підписуємо окремо, бо модель може помилитися. Якщо локальні правила не підтверджують конкретних ознак, прямо це пишемо. У розмові з кількома повідомленнями картка залишається біля свого листа.

Кольори за призначенням: темно-сіре тло й картки, світлий текст, лайм для основної кнопки; кораловий для «підозрілий», бурштиновий для «потрібна перевірка», приглушений бірюзовий для «явних ознак не знайдено». Кожен стан також має текст та іконку, тому колір не є єдиним сигналом.

Окремі службові картки: «Потрібна згода», «Аналіз триває…», «Аналіз недоступний» з кнопкою повтору. Перед згодою показуємо шлях даних: через backend до Laya або через backend до OpenRouter/TypeSafe. Пояснюємо, що згода запам’ятовується для вибраної адреси backend і режиму та дозволяє автоматично перевіряти наступні відкриті листи.

## Налаштування

Та сама темна тема: поле **адреси backend** (`http://127.0.0.1:8787`), перемикач Laya/Jev, «Зберегти» і «Відкликати згоди». Ключ OpenRouter сюди не вводиться. Мінімальний текст 14 px, видимий фокус клавіатури, довгі адреси переносяться.
